# Reverse Complement Tool

A Python tool for generating the complementary and reverse complement sequences of DNA.

This program takes a DNA sequence as input, validates it, generates its complementary sequence, and reverses the complement to produce the reverse complement.

## Features

* Converts DNA sequences to uppercase.
* Validates DNA sequences using the four standard bases (`A`, `T`, `G`, `C`).
* Handles empty input and invalid DNA sequences.
* Generates the complementary DNA sequence.
* Generates the reverse complement sequence.
* Displays the original DNA, complement, and reverse complement.

## Example

**Input:**

```text
ATGC
```

**Output:**

```text
Valid DNA sequence
Original DNA: ATGC
Complement DNA: TACG
Reverse Complement DNA: GCAT
```

## How to Run

1. Make sure Python is installed.
2. Clone or download this repository.
3. Open a terminal in the project folder and run:

```bash
python reverse_complement_tool.py
```
